# 41014 42043 TurtleBot3 simulation

## Explanation
Simulation of turtlebot3 in MuJoCo simulator. The robot must navigate a room with obstacles using the LiDAR and visually dock to the ArUco-marked goal.

## Run commands
To run the simulation use:

cd to the MuJoCo_turtlebot3_simulation directory
```bash
cd MuJoCo_turtlebot3_simulation
```
Run the main.py
```bash
python main.py
```
The mujoco viewer will appear with the simulated world.

To see the camera feed from the robot change the 'draw' variable to true in main.py

To use other scene change the SCENE variable in config.py
## AI Decleration
claude was used to generate the scene and the map.npy. The obstacles was added manually.

Claude was used to refactor the code from the testing branch to submodules

claude was used in estimation_control.py in the path generator class to create a function that estimates normals for 2d pointclouds. The difference is that in the 2d normals calulation the z is 0.

claude was also used in the path generator class to create a function that takes in waypoints of the path and the estimated state to calulate the crosstrack and heading error. it first calculate the length of each segements and rejects zero lengths. it then finds the closest points on the line segemnt to the robot. It finds the distance of each valid line segment to the robot and picks the shortest one. This segement is where the current is currently navigating and the errors are calulated based on this segment.

claude is used in the groundtruthlogger to use np.linalg.solve and get anees (previous assignment)

claude is used in the sensors.py to visualise the lidar in the mujoco scene.

generate_aruco_png.py was generated by gemini to generate 50 aruco marker.
